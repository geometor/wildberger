geometor.wildberger.invariants¶

Exact algebraic invariants for Rational Trigonometry and Universal Geometry.

Implements quadrance, spread, cross, twist, quadrea (Archimedes’ function), spread polynomials, projective line and conic proportions, 3D dihedral spreads, cross-ratio quadrance/spread invariants, finite-field arithmetic over GF(p), and universal symmetric bilinear metric forms (Blue, Red, and Green Chromogeometry) using 100% exact SymPy symbolic expressions.
