geometor.wildberger.invariants
==============================

.. py:module:: geometor.wildberger.invariants

.. autoapi-nested-parse::

   Exact algebraic invariants for Rational Trigonometry and Universal Geometry.

   Implements quadrance, spread, cross, twist, quadrea (Archimedes' function),
   spread polynomials, projective line and conic proportions, 3D dihedral spreads,
   cross-ratio quadrance/spread invariants, finite-field arithmetic over GF(p),
   and universal symmetric bilinear metric forms (Blue, Red, and Green
   Chromogeometry) using 100% exact SymPy symbolic expressions.

.. py:function:: collinear_det(p1: Point2DInput, p2: Point2DInput, p3: Point2DInput) -> sympy.Expr

   Compute the collinearity determinant `x1*y2 - x1*y3 + x2*y3 - x3*y2 + x3*y1 - x2*y1`.

   :param p3: Third point `[x3, y3]`.

.. py:function:: spread(l1: LineProportion, l2: LineProportion, metric: MetricForm = BLUE_METRIC) -> sympy.Expr

   Compute the spread `s_M(l1, l2) = 1 - c_M(l1, l2)` between two non-null lines.

   For Euclidean Blue geometry:
   `s(l1, l2) = (a1*b2 - a2*b1)^2 / ((a1^2 + b1^2)*(a2^2 + b2^2))`.

   :param l1: First non-null line.
   :param l2: Second non-null line.
   :param metric: Symmetric bilinear metric form.

   :returns: Exact spread invariant `s`.

   :param l1: First non-null line.
   :param l2: Second non-null line (not orthogonal to `l1`).
   :param metric: Symmetric bilinear metric form.

   :returns: Exact twist invariant `t = s / c`.


.. py:function:: signed_turn(l1: LineProportion, l2: LineProportion) -> sympy.Expr

   Compute Wildberger's oriented turn `u(l1, l2) = (a1*b2 - a2*b1) / (a1*a2 + b1*b2)`.

   Satisfies `u(l1, l2)^2 = t(l1, l2)` (the twist) and the rational tangent-addition
   Triple Turn Formula `u1 + u2 + u3 = u1 * u2 * u3` when `l1, l2, l3` cycle!

   :param l1: First oriented line.
   :param l2: Second oriented line.

   :returns: Exact signed turn expression.

.. py:function:: quadruple_quad_function(q1: CoordScalar, q2: CoordScalar, q3: CoordScalar, q4: CoordScalar) -> sympy.Expr

   Evaluate Wildberger's Quadruple Quad polynomial `Q(a, b, c, d)` (Theorem 31).

   `Q(a,b,c,d) = ((a+b+c+d)^2 - 2(a^2+b^2+c^2+d^2))^2 - 64*a*b*c*d`.
   Vanishes for four collinear point quadrances OR when a cyclic quadrilateral
   has zero cyclic quadrea (degenerate case).

   :param q1: First quadrance.
   :param q2: Second quadrance.
   :param q3: Third quadrance.
   :param q4: Fourth quadrance.

   :returns: Exact polynomial value.

.. py:function:: euler_four_point_function(q1: CoordScalar, q2: CoordScalar, q3: CoordScalar, p1: CoordScalar, p2: CoordScalar, p3: CoordScalar) -> sympy.Expr

   Evaluate Euler's Four-Point planar Cayley-Menger relation `E(Q1, Q2, Q3, P1, P2, P3)` (Theorem 115).

   Vanishes for the six pairwise quadrances of ANY four coplanar points `A1, A2, A3, A4`,

   :param p2: `Q(A2, A4)`.
   :param p3: `Q(A3, A4)`.

   :returns: Exact polynomial value (zero for any four coplanar points).


.. py:function:: spread_polynomial(n: int, s: CoordScalar) -> sympy.Expr

   Compute Wildberger's n-th Spread Polynomial `S_n(s)`.

   Defined over Z[s] by `S_0(s) = 0`, `S_1(s) = s`, and
   `S_n(s) = 2*(1 - 2*s)*S_{n-1}(s) - S_{n-2}(s) + 2*s`.

   :param n: Non-negative degree index.
   :param s: Spread variable or exact value.

   :returns: Expanded exact polynomial expression `S_n(s)`.

   :raises ValueError: If `n < 0`.

   :param n: Non-negative degree index.
   :param c: Cross variable or exact value `c = 1 - s`.

   :returns: Expanded exact polynomial expression `C_n(c)`.
